Studio Video JuaraTKA

Panel materi jadi video TikTok / Shorts, lengkap dengan suara Bapak.

1. Pilih materi

Data diambil dari GitHub. Pakai JSON lokal untuk materi yang belum di-push.

Gambar dicocokkan lewat nama file di JSON. Lokal dipakai dulu, lalu GitHub img/.

2. Pilih avatar

3. Rekam suara per adegan

Klik adegan, tekan Rekam (atau tombol R) lalu bacakan teksnya, atau Unggah file suara dari AI (MP3/WAV/M4A). Hening di awal dan akhir dipotong otomatis, nama file diatur saat diunduh.

4. Iklan penutup

Tampil di akhir video. Angka di kalimat pancingan dianimasikan menghitung naik (kecuali tahun). Boleh pakai {soal} untuk jumlah soal latihan dari config.json.
